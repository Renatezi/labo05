# Guía de Contribución

¡Gracias por tu interés en colaborar con este proyecto!

## Cómo reportar un error
Si encuentras algún problema o bug, por favor abre un *Issue* en el repositorio indicando:
1. Una descripción clara del error.
2. Los pasos detallados para reproducirlo.
3. El comportamiento esperado frente al comportamiento actual.

## Cómo proponer una mejora
Las ideas y nuevas funcionalidades son bienvenidas. Para proponer una mejora:
1. Abre un *Issue* con la etiqueta `enhancement` (mejora).
2. Describe tu propuesta detalladamente y explica por qué sería útil para el proyecto.

## Checklist para Pull Requests
Antes de enviar un Pull Request (PR), por favor asegúrate de revisar la siguiente lista:

- [ ] He leído esta guía de contribución.
- [ ] Mi código sigue el estilo y convenciones del proyecto.
- [ ] He probado mis cambios localmente y funcionan correctamente.
- [ ] He documentado mis cambios si es una nueva funcionalidad.
